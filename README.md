# 🛒 E-Commerce Customer Churn & Retention Analysis

An end-to-end customer analytics project designed to evaluate customer behavior, churn drivers, and purchasing patterns in an e-commerce platform. This project leverages **SQL** for relational data querying and feature extraction, **Python** for exploratory data analysis and statistical validation, and **Tableau** for interactive business reporting.

---

## 📌 Executive Summary
* **Objective:** Analyze e-commerce customer transaction history and interaction metrics to pinpoint key indicators of customer churn and build actionable retention strategies.
* **Core Skills Demonstrated:** Advanced SQL queries (Window functions, CTEs, aggregation), Python EDA, Customer Segmentation (RFM analysis), and Tableau Dashboarding.
* **Tech Stack:**
  * **Database & Querying:** SQL (SQLite / PostgreSQL)
  * **Exploratory Analysis:** Python (`Pandas`, `NumPy`, `Seaborn`, `Matplotlib`)
  * **Business Intelligence:** Tableau Desktop / Tableau Public
  * **Version Control:** Git & GitHub
